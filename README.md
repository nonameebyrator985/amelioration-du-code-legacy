# Amélioration du Code Héritage

Ce projet a pour but de refactoriser une application existante qui utilise du code hérité, souvent difficile à maintenir et à étendre. L'objectif est de:

- **Moderniser** le code en utilisant des standards de développement récents.
- **Ajouter des tests automatisés** pour garantir que les modifications n'introduisent pas de régressions.
- **Documenter le code** pour améliorer la compréhension et la pérennité de l'application.

## Fonctionnalités
- Refactorisation du code.
- Création de tests unitaires et d'intégration.
- Mise en place de l'intégration continue.
